学ぶポイント
  • スケジュール式: rate と cron rate(5 minutes) は5分ごとに繰り返す。cron(0 9 * * ? *) は毎日9時に実行。EventBridge Scheduler は1回限り・タイムゾーン指定にも対応。
  • イベントバス + ルール + ターゲット イベントをパターンでフィルタし、複数ターゲット（Lambda・SQS・SNS等）へ配信する疎結合ハブ。発行側はターゲットを知らなくてよい。
  • イベントパターン source / detail-type / detail のフィールド値が一致したイベントのみターゲットへ配信。一致しないイベントは自動的に捨てられる（課金なし）。
  • cron ポーリングとの違い EventBridge はポーリング不要のイベント駆動。AWS サービス間連携（S3→Lambda 等）も同じ仕組みで、スケールしてもコード変更なし。
