API の違い

  

    

      

        
InvokeModel

        
モデル固有のリクエスト/レスポンス形式。Claude の場合は anthropic_version フィールドが必須。ボディを直接 JSON シリアライズして渡す。

        

          POST /model/{modelId}/invoke

          Content-Type: application/json
        

      

      

        
Converse API 推奨

        
マルチベンダ共通インターフェース。モデル ID を差し替えるだけで Titan・Llama 等にも切替可能。messages 形式は Claude と同一。

        

          POST /model/{modelId}/converse

          SDK: bedrock_runtime.converse(...)

学ぶポイント

  
    
    
  • 
      基盤モデル (FM)
      Bedrock 経由で複数ベンダのモデルを同一 API 体系で呼ぶ。Claude は Messages/Converse 形式でアクセスする。
    
    • 
    
  • 
      Messages API の形
      system + messages[](role:user/assistant) + max_tokens + temperature。出力は content ブロック配列として返される。
    
    • 
    
  • 
      temperature と max_tokens
      temperature で多様性（0=決定論的、1=クリエイティブ）を制御。max_tokens 到達時は stop_reason: "max_tokens" が返る。
    
    • 
    
  • 
      ストリーミングと IAM 権限
      ストリーミング呼び出しでトークンを逐次受信できる。呼び出しには IAM ポリシーで bedrock:InvokeModel 権限が必要。
    
    •
