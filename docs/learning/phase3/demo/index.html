学ぶポイント
  • 疎結合 — バッファとしてのキュー Producer と Consumer を時間的に切り離し、急なスパイクをキューが吸収する。Consumer がダウンしていてもメッセージは失われない。
  • 可視性タイムアウト 取り出し中のメッセージを他のコンシューマから一時的に隠す時間。処理が長引いてタイムアウトすると、メッセージは Queue に戻り再配信される。
  • at-least-once 配信（最低1回） SQS は重複配信が起こり得る。処理は冪等（idempotent）に設計する必要がある。FIFO キューは exactly-once を保証する。
  • DLQ — デッドレターキュー maxReceiveCount を超えた「毒メッセージ」を退避させ、本線のキューが詰まるのを防ぐ。Standard は順不同・FIFO は順序保証と重複排除付き。
