ハンズオン — 実 AWS sandbox を動かす

普段は無料で検証し、CloudWatch を見たい時だけ短時間 apply→観測→destroy します。apply から実課金が始まるので、終わったら必ず destroy してください。

  1. 無料検証（課金なし · moto + terraform validate）make sandbox-test-phase2
  2. デプロイ（実課金開始）make sandbox-up-phase2
  3. 負荷生成 — オブジェクトを put（ObjectCreated→Lambda が発火）make sandbox-load-phase2
  4. 観測 — Lambda Invocations（即時）。S3 ストレージ系メトリクスは日次make sandbox-watch-phase2
    ⏱ Lambda は数分、ストレージ系は翌日
  5. 後片付け（課金停止）make sandbox-down-phase2

📋 もっと詳しく: 各コマンドの期待出力・観察ポイントのチェックリスト・トラブルシュート・コスト目安は ハンズオン詳細（HTML） ／ md を参照。

⚠ バケットは force_destroy 済みなのでオブジェクトが残っていても destroy できる。
