学ぶポイント

  • オブジェクトストレージ ファイル/ブロックと違い「キー + メタデータ + 本体」の塊として扱う。部分更新はできず、常に丸ごと PUT/GET する。
  • キー空間はフラット スラッシュは見た目のフォルダに過ぎず、実体はフラットなキー空間。プリフィックスで一覧・権限を区切る。
  • プリサインド URL 署名付き期限付き URL で、認証情報を渡さず一時的にアップロード/ダウンロードを許可できる。期限切れは 403。
  • ストレージクラス Standard / IA / Glacier はコストと取り出し時間のトレードオフ。PUT 直後も強整合 (read-after-write) でデータは即座に読める。
