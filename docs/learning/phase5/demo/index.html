学ぶポイント
  • エッジキャッシュ: MISS → HIT の仕組み 初回リクエストはオリジンまで到達 (Cache MISS)。TTL 満了か Invalidation まではエッジから直接応答 (Cache HIT) され、レイテンシが大幅に短縮される。
  • CloudFront の役割 S3 / API Gateway の前段に置き、レイテンシ削減・オリジン負荷軽減・TLS 終端を一手に引き受ける。エッジロケーションは世界 400+ 拠点に展開。
  • WAF Web ACL: 優先度順評価 ルールは Priority の小さい順に評価。最初にマッチしたルールの Action (ALLOW / BLOCK / COUNT) が適用され、以降はスキップされる。
  • レートベースルール: 簡易 DoS 対策 一定時間ウィンドウ内のリクエスト数を IP 単位で集計し、閾値超過を自動 BLOCK。スクレイピングやブルートフォースにも有効。
