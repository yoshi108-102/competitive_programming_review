サンプリングレート シミュレーター

サンプリング割合 (青=記録、灰=スキップ)
学ぶポイント
  • トレース・セグメント・サブセグメント トレースは 1 リクエストの全体。サービス単位の記録が segment、その下位呼び出し (DB・HTTP) が subsegment に分解される。
  • サンプリングでコスト最適化 全リクエストを記録すると費用がかさむため、X-Ray はデフォルトで先頭 1 req/秒 + 5% をサンプリング。レートはルールで調整できる。
  • annotation vs metadata annotation はインデックス化されてコンソールで検索可能。metadata は任意の付帯情報を格納できるが検索対象外。
  • サービスマップでボトルネック特定 ノード＋エッジのグラフでエラー源と高レイテンシ箇所を俯瞰し、ウォーターフォールで時系列の内訳を深掘りする。
