Step Functions — ステートマシンを実行

AWS Step Functions はワークフローを JSON（ASL）で宣言的に定義し、各状態（State）を順番に実行するサーバーレスオーケストレーターです。状態遷移・リトライ・エラー捕捉がコード不要で制御できます。

学ぶポイント

  
    
    
  • 
      状態の種類
      Task / Choice / Parallel / Map / Wait / Pass / Succeed / Fail を ASL（JSON）で宣言的に記述。コードではなく設定でフロー制御できる。
    
    • 
    
  • 
      入出力処理
      各状態が入力 JSON を受け取り出力を次の状態へ渡す。InputPath / ResultPath / OutputPath で JSON の抽出・合成を細かく制御できる。
    
    • 
    
  • 
      Retry と Catch
      例外ごとに指数バックオフ再試行、捕捉して代替パスへ分岐。Lambda 内の try/except を超えたワークフローレベルの例外制御が実現できる。
    
    • 
    
  • 
      Standard vs Express
      Standard は長時間・履歴あり（最大 1 年）、Express は高頻度・低コスト（最大 5 分）。可視化コンソールで失敗箇所が一目で分かる。
