ハンズオン — 実 AWS sandbox を動かす

普段は無料で検証し、CloudWatch を見たい時だけ短時間 apply→観測→destroy します。apply から実課金が始まるので、終わったら必ず destroy してください。

  1. 無料検証（課金なし · moto + terraform validate）make sandbox-test-phase1
  2. デプロイ（実課金開始）make sandbox-up-phase1
  3. 負荷生成 — 無認証トラフィックを生成（テストユーザー不要）。認証あり負荷は TEST_PASSWORD=... make sandbox-load-phase1make sandbox-load-phase1
  4. 観測 — API GW の Count / 4XXError / Latency、Lambda、DynamoDB、Cognito メトリクスmake sandbox-watch-phase1
    ⏱ 反映まで 2〜5 分
  5. 後片付け（課金停止）make sandbox-down-phase1

⚠ phase1 は本番スタックを観測するダッシュボードのみ作成（本番アプリは別途デプロイ済みが前提）。
