学ぶポイント

01

Namespace + Dimensions で識別

メトリクスは namespace + dimensions の組で一意に決まる時系列。period と統計（Average/Sum/p99）の組み合わせで集計結果が変わる。

02

アラームは 3 状態を持つ

OK / ALARM / INSUFFICIENT_DATA。「直近 M 中 N がしきい値超え」で ALARM に遷移し、SNS アクションで通知や Auto Scaling を起動できる。

03

Logs と Metrics は別物

ログは生テキスト（構造化 JSON 推奨）、メトリクスは数値時系列。Logs Insights でログを高速検索・集計できる。

04

構造化ログの恩恵

JSON フォーマットにするとフィールド単位フィルタが容易になり、メトリクスフィルタで自動的にメトリクスを抽出できる。

詳細は docs/learning/phase4/preview-cloudwatch.md を参照
