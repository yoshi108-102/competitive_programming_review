学ぶポイント

  • メトリクス: namespace + dimensions で識別される時系列 期間(period)と統計(Average/Sum/p99)で集計する。同じ測定値でも集計方法次第で見え方が変わる。
  • アラーム: 「直近 M 中 N がしきい値超え」で状態遷移 OK / ALARM / INSUFFICIENT_DATA の 3 状態を持つ。アクションに SNS を紐付けると通知や Auto Scaling が起動できる。
  • Logs と Metrics は別物 ログは生テキスト(構造化 JSON 推奨)、メトリクスは数値時系列。Logs Insights でログを検索・集計できる。
  • 構造化ログ(JSON)にしておくと恩恵が大きい フィールド単位のフィルタ、メトリクスフィルタによる自動メトリクス抽出が容易になる。
